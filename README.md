# 100 программ Python — тренажёр переписывания кода

Статический сайт-сборник: 100 мини-программ на Python, которые ученик перепечатывает руками, запускает и дорабатывает. Связан с основным сайтом курса «Python для дундриков» взаимными ссылками.

## Структура

- `index.html` — вся разметка и стили (стиль повторяет python30-site)
- `src/tasks.js` — данные всех 100 задач (код хранится в `String.raw`, чтобы обратные слэши Python не ломались)
- `src/main.js` — сетка задач, фильтры, поиск, диалог с подсветкой кода, прогресс в localStorage
- `server.js` — локальный preview-сервер без зависимостей (`npm run dev -- --port 7100`)

## Запуск локально

```bash
npm run dev
# или напрямую: node server.js --port 7100
```

## Публикация на GitHub Pages (связка с python30-site)

1. Создай репозиторий `python100` на github.com/pallach8698 и залей туда содержимое этой папки.
2. В настройках репозитория: Settings → Pages → Source → `main` / `root`.
3. Сайт станет доступен по адресу `https://pallach8698.github.io/python100/`.
4. Чтобы связать два сайта, добавь в навигацию `python30-site/index.html` ссылку:

```html
<a href="https://pallach8698.github.io/python100/">100 задач</a>
```

Обратная ссылка на курс уже встроена в этот сайт (кнопка «Курс „30 дней“» в шапке, блок «Переписал все 100?» и футер).

## Особенности

- Прогресс хранится в `localStorage` браузера (ключ `py100-done`) и никуда не отправляется.
- Все 100 программ проверены на синтаксическую корректность (compile() в Python 3).
- Используется только стандартная библиотека Python; задачи 63–66 требуют встроенный модуль turtle.
