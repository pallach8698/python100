Как заниматься

Метод называется «learn by typing»: медленный набор кода руками заставляет вчитываться в каждую строку — и это работает лучше, чем десять прочитанных уроков.

Выбери программу

Начни с уровня «лёгкая». Открой карточку задачи и прочитай, что программа должна делать.

Перепиши руками

Создай пустой файл .py и набери код целиком сам. Не копируй и не вставляй — в этом весь смысл.

Вопросы

Почему нельзя копировать код?

Потому что копипаста обманывает мозг: кажется, что понял, а на деле — пропустил. Медленный набор руками заставляет замечать каждое двоеточие и отступ, а исправление собственных опечаток учит читать ошибки. Это медленнее, но именно так код переходит в навык.

Как запустить программу?

Сохрани набранный код в файл, например igra.py, и запусти командой python igra.py в терминале. Можно также использовать IDLE — она ставится вместе с Python. Программы-анимации останавливаются клавишами Ctrl+C.

Нужно ли что-то устанавливать?

Только Python 3 с официального сайта python.org. Все 100 программ используют стандартную библиотеку — никаких pip install. Программы с черепашкой используют встроенный модуль turtle.

Где хранится мой прогресс?

Отметки о выполненных задачах сохраняются в хранилище этого браузера на твоём устройстве и никуда не отправляются. Если очистить данные браузера, прогресс обнулится.

Windows предупреждает о неизвестном издателе при запуске приложения — это опасно?

Нет. Приложение собрано из открытого кода (он в репозитории на GitHub) и пока не имеет платной цифровой подписи, поэтому Windows проявляет осторожность. Нажми «Подробнее» → «Выполнить в любом случае». Скачивай файл только с этого сайта.
